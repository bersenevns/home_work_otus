# Spine-Leaf Topology Addressing

## Описание топологии

В лаборатории реализована классическая **spine-leaf архитектура**, состоящая из:

- 2 Spine-коммутаторов
- 3 Leaf-коммутаторов

---

## Обоснование схемы адресации

В реальных production-сетях часто используется агрегируемая и экономная адресация (/31, /30, summarization и т.д.).

Однако в рамках учебной лабораторной работы приоритет был отдан:

- простоте понимания
- быстрому troubleshooting
- визуальной привязке IP → физическое соединение
- читаемости топологии без необходимости дополнительной документации

Таким образом, выбран подход:

> “один линк = одна подсеть /30, с очевидной нумерацией по устройствам”

---

## IP Addressing Scheme

Используется приватный диапазон:

10.10.X.Y/30

Где X имеет два разряда: 
- первый → № Spine
- второй → № Leaf

Где Y адресует 
- Spine → `.1`
- Leaf → `.2`

---

## Таблица адресации

### Spine 1 connections

| Link    | Network       | Spine Port | Spine IP   | Leaf IP    | Leaf Port |
|---------|---------------|------------|------------|------------|-----------|
| S1 ↔ L1 | 10.10.11.0/30 | eth1       | 10.10.11.1 | 10.10.11.2 | eth8      |
| S1 ↔ L2 | 10.10.12.0/30 | eth2       | 10.10.12.1 | 10.10.12.2 | eth8      |
| S1 ↔ L3 | 10.10.13.0/30 | eth3       | 10.10.13.1 | 10.10.13.2 | eth8      |

---

### Spine 2 connections

| Link    | Network       | Spine Port | Spine IP   | Leaf IP    | Leaf Port |
|---------|---------------|------------|------------|------------|-----------|
| S2 ↔ L1 | 10.10.21.0/30 | eth1       | 10.10.21.1 | 10.10.21.2 | eth7      |
| S2 ↔ L2 | 10.10.22.0/30 | eth2       | 10.10.22.1 | 10.10.22.2 | eth7      |
| S2 ↔ L3 | 10.10.23.0/30 | eth3       | 10.10.23.1 | 10.10.23.2 | eth7      |

---

## Интерфейсная логика

### Spine downlinks

- `eth1` → Leaf 1
- `eth2` → Leaf 2
- `eth3` → Leaf 3

### Leaf uplinks

- `eth8` → Spine 1
- `eth7` → Spine 2

---

## Итог

Данная схема обеспечивает:

- простую и предсказуемую адресацию
- быструю идентификацию линков по IP
- удобный troubleshooting в лабораторной среде
- масштабируемость (добавление новых leaf/spine по аналогии)
